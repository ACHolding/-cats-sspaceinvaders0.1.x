CAT'S SPACE INVADERS 0.1 — M-Chip GUI
Copyright (c) AC Kondo 1999-2026
600x400 centered native macOS Cocoa window, 60 FPS target.
Menu: PLAY, HELP, ABOUT, EXIT. Arrows/Enter or mouse.
Game: A/D or arrows move, Space fire, P pause, R restart, Esc menu.
Procedural Famicom-style square-wave/triangle-wave sound effects (original tones, not Nintendo audio recordings).
Build on Apple Silicon macOS: sh build_mac.sh
Run: ./CatsSpaceInvaders-MChip
Requires macOS 12+, Xcode Command Line Tools. No external assets.
Note: source was not compiled on macOS in this Linux environment.
